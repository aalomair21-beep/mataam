# مزامنة نسخة التصفّح

- `snapshot.json`: نسخة من تعديلات قاعدة بيانات «حلال» (بدون الصور).
- `app-src.html`: نسخة من كود صفحة «حلال» الكامل. حدّثه كل ما تغيّر كود الصفحة.
- `build.js`: يبني `app.html` (نسخة التصفّح) من الاثنين.
- `merge.py new.jsonl`: يضيف المستندات الجديدة (اللي `at` حقها أكبر من `last_at.txt`) ويبني.
